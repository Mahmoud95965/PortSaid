# دليل تشغيل مشروع Port Said Hub (Next.js + Supabase) 🌊

تم تحويل المشروع بالكامل وبنجاح من **PHP وقاعدة بيانات MySQL** إلى تطبيق عصري مبني بـ **React.js & Next.js 14 (App Router) مع TypeScript و Tailwind CSS**، وتجهيز ملف **SQL كامل وشامل لـ Supabase (PostgreSQL)** مع الحفاظ على التصميم بنسبة 100%، والهوية البصرية، والخطوط، والوضع الليلي/النهاري، وكافة المميزات والوظائف.

---

## 📁 محتويات المشروع الجديدة

1. **`supabase_schema.sql`**: ملف SQL كامل وجاهز للتشغيل مباشرة في Supabase بنقرة واحدة.
2. **`src/`**: الكود البرمجي الكامل لتطبيق Next.js:
   - `src/app/page.tsx`: الشاشة الرئيسية التفاعلية وشاشات الأقسام (المواصلات، السكن، المطاعم، المعالم، الكوبونات، التقييمات، إلخ).
   - `src/app/admin/page.tsx`: لوحة التحكم الإدارية المتكاملة (`/admin`).
   - `src/app/verify/page.tsx`: صفحة توثيق البريد الإلكتروني.
   - `src/app/api/assistant/route.ts`: واجهة برمجة شات بوت "مساعد بورسعيد" بالذكاء الاصطناعي مع دعم الرد الذكي الجاهز.
   - `src/components/`: المكونات التفاعلية (الهيدر، الفوتر، شاشة الترحيب، تسجيل الدخول/إنشاء الحساب، كود الـ QR، معرض الصور، شات بوت المساعد، إلخ).
   - `src/context/AuthContext.tsx`: إدارة جلسات المستخدمين، الصلاحيات، النقاط، والمظهر الليلي/النهاري.
   - `src/lib/constants.ts`: كتالوج التصنيفات، شبكة خطوط المواصلات الحسابية، وقائمة الأسئلة الشائعة.
   - `src/lib/supabase/client.ts`: ربط موحد مع Supabase مع دعم العمل المباشر التجريبي دون انقطاع.
3. **`public/assets/`**: تم نقل كافة الصور، الشعارات، الأيقونات، وخلفيات بورسعيد التاريخية إلى مجلد الأصول الثابتة.
4. **`legacy_php/`**: تم أرشفة ملفات PHP القديمة بأمان تام كمرجع إضافي دون التأثير على عمل Next.js.

## 🚀 خطوة 1: تجهيز قاعدة بيانات Supabase

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. من القائمة الجانبية اليسرى، ادخل إلى **SQL Editor**.
3. افتح الملف المرفق **`supabase_schema.sql`** وانسخ محتواه بالكامل، ثم الصقه في محرر Supabase واضغط على **Run**.
4. ستقوم الأوامر بإنشاء:
   - جميع الجداول الـ 20+ (المستخدمين، الأدوار، الصلاحيات، الأماكن، خطوط المواصلات، الزيارات، الكوبونات، العمولات، التقييمات، الشكاوى، طلبات التجار، وسجل النشاط التشفيري).
   - سياسات الأمان والحماية (Row Level Security - RLS).
   - الدوال ومحفزات التحديث التلقائي للوقت (Triggers).
   - **البيانات الأولية الجاهزة (Seed Data)**:
     - كافة محافظات مصر الـ 27.
     - كليات جامعة بورسعيد والجامعة الأهلية والمدارس.
     - تصنيفات الأماكن وأيقوناتها وألوانها.
     - خطوط المواصلات الحقيقية (الأمين، الزهور، الـ 5000، التلاتيني، السلام، أسوان).
     - أماكن ومعالم أولية (فنار بورسعيد، ممشى ديليسبس، مطاعم كاستن، كافيهات، وسكن الطلبة).
     - حساب المالك الافتراضي:
       - **البريد:** `admin@portsaidhub.com`
       - **كلمة المرور الأولية:** `Admin@123456`

## 🔑 خطوة 2: ربط المشروع بـ Supabase

افتح الملف **`.env.local`** في المجلد الرئيسي وضع به مفاتيح مشروعك من Supabase (من صفحة **Project Settings > API**):

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here

# اختياري: مفتاح الذكاء الاصطناعي لشات بوت مساعد بورسعيد (يعمل تلقائياً بالأسئلة الذكية في حال عدم وضعه)
ANTHROPIC_API_KEY=
```

---

## 💻 خطوة 3: تشغيل المشروع محلياً

لتشغيل سيرفر التطوير على جهازك:

```bash
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

لبناء المشروع للإنتاج (Production Build):
```bash
npm run build
npm start
```

## ✨ المميزات المحولة والمطورة بالكامل:

1. **شاشة ترحيب تفاعلية**: صور بورسعيد المتحركة وزر البدء السلس مع حفظ الحالة.
2. **تسجيل الدخول وإنشاء الحساب متعدد الخطوات**:
   - للزائر العادي (طالب، سائح/مغترب، من بورسعيد).
   - للتاجر وصاحب النشاط (اسم المتجر، المنطقة، نسبة الخصم، عمولة TOLZY).
3. **نظام النقاط والمكافآت**:
   - زيارة الأماكن والتحقق من الموقع الجغرافي بالـ GPS باستخدام خوارزمية Haversine وحساب المسافة بدقة المتر.
   - شير واكسب على واتساب (+40 نقطة تلقائياً).
4. **كوبونات الخصم الديناميكية**:
   - توليد أكواد QR حية برمجياً مع عداد تنازلي لصلاحية الكود.
5. **مخطط المواصلات الذكي**:
   - حساب خطوط السير التبادلية والمحطات الفرعية بين الكليات وسكن الطلاب.
6. **دليل السكن**:
   - تصفية السكن بحسب أحياء بورسعيد المختلفة.
7. **استكشف بورسعيد**:
   - معرض صور بورسعيد مع مستعرض صور Lightbox عالي الجودة وخاصية رفع صور الزوار.
8. **شات بوت مساعد بورسعيد**:
   - زر عائم، واجهة محادثة متجاوبة، أسئلة شائعة بنقرة واحدة، ودعم الذكاء الاصطناعي.
9. **لوحة التحكم الإدارية الكاملة (`/admin`)**:
   - إدارة المستخدمين وتعديلهم وتعطيلهم.
   - إدارة فريق العمل وصلاحيات الأدمن التفصيلية.
   - مراجعة طلبات التجار وقبولها وربطها بالأماكن.
   - تسوية الكوبونات بالمحل.
   - سجل النشاط التشفيري مع خاصية التحقق من سلامة السلسلة التشفيرية.
10. **الوضع الليلي والنهاري (Dark / Light Theme)**:
    - حفظ تفضيل المستخدم في `localStorage` ومطابقة تامة لألوان الموقع الأصلية.
